# WASPRO-M: polish visual menyeluruh

Tanggal pengerjaan: 11 November 2026 (WIB).

## Cakupan

Polish ini melanjutkan audit sebelumnya, bukan mengganti implementasi atau menghapus perubahan lokal. Semua layar memakai sistem visual bersama: login, beranda, menu Limbah/FABA/Tinjau/Lainnya, daftar dan detail, editor, draft, master data, akun, persetujuan, rekap, laporan, serta state loading/error/kosong.

## Perubahan

- Tipografi IBM Plex dipertahankan dengan hierarki judul yang lebih ringkas, radius 12/18/24 dp, dan jarak antarkomponen konsisten.
- Navigasi aktif menggunakan ikon terisi; tujuan lain memakai outline. Ikon menu/persetujuan/master data disesuaikan dengan konteks modul.
- Kartu catatan lebih padat; judul, metadata, kuantitas, dan status dipisahkan dengan jelas. Status memakai ikon sekaligus teks, bukan warna saja.
- Dashboard membedakan ukuran angka dan satuan, menyesuaikan jumlah kolom dengan lebar/font, serta mengurangi tinggi disclosure tanpa mengecilkan target sentuh 48 dp.
- Menu modul berubah menjadi dua kolom bila konten minimal 600 dp dan ukuran font memungkinkan. Pada font besar kembali ke satu kolom. Navigation rail tablet tetap dipertahankan.
- Form dikelompokkan menjadi bagian bernomor. Tombol simpan tetap di luar scroll, dengan ikon unggah dan tinggi minimal 48 dp. Input, dropdown, error, draft, dan keyboard tetap menggunakan perilaku sebelumnya.
- Laporan menjadi tiga panel: jenis laporan, periode/material/filter, dan format/unduh. Periode ditumpuk vertikal pada layar sempit atau font besar, dan pilihan material aktif mendapat tanda centang.
- Status pembaruan/cache/error punya area tersendiri. Tombol utama serta ekspor diseragamkan.
- Foto stasiun, font berlisensi, dan ikon native yang sudah ada dipakai ulang. Tidak menambah bitmap dekoratif karena layar ini berorientasi data operasional.
